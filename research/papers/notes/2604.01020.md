## Setup
- Tasks / benchmarks (coding? repo-level? research? planning?): MuSR narrative reasoning (accuracy), MuSiQue multi-hop QA and SQuAD 2.0 answerability (F1); no repository work.
- Models used (per role): GPT-5 mini, GPT-OSS-120B, Llama-3.1-8B, evaluated separately; each organization uses the same backbone across its roles (§4.1, p.5). Skill names are prompts, not separately trained specialist models.
- Baselines (single agent? flat team? budget-matched? yes/no + how): single agent and flat peers with the same named functional roles. Not budget matched: flat capped at three rounds; hierarchy permits governance rounds plus execution rounds and additional output control (Appendix A.3/Table 5, p.13). Reports consumed tokens, not equal-total-token comparisons.

## Topology tested
- Depth: 0 = single agent · 1 = orchestrator → workers · 2 = orchestrator → sub-orchestrators → workers · recursive: single agent, peer organization, and governance → execution → compliance workflow. This is NOT a clean depth-1 versus depth-2 command-tree ablation: compliance is downstream checking, not a second management tier (Figure 2, p.3).
- Width (workers per orchestrator) and how it was varied: governance CEO/CTO/COO; execution DIRECT = drafter, LIGHT = drafter+reviewer, FULL = drafter+reviewer+specialist; output CSO+CCO. Six skill profiles available to drafter/specialist. No width scaling curve.
- Roles (planner, implementer, verifier, reviewer, integrator, router, ...): CEO strategic approval, CTO skill assignment, COO resources; drafter writes/revises, reviewer critiques, specialist advises; CSO finalizes, CCO checks schema only (§3.2–3.6, pp.3–5).
- Communication / handoff format; who can write code/files: flat shares task/context among peers; hierarchy passes configuration and drafts through stages. Text answers, no file ownership or merge protocol. Governance maximum three rounds; DIRECT/LIGHT/FULL execution ceilings 1/3/5 (Table 5).

## Findings (quote numbers with table/figure/page refs)
- Depth (when does more depth help or hurt?): GPT-5 mini MuSiQue rises from flat 50.31 to hierarchical 68.98 F1; GPT-OSS SQuAD rises 31.12→63.09 (+102.73% relative). Conversely GPT-OSS MuSR falls 69.00→59.50 accuracy and Llama falls 37.41→34.00 (Table 1, p.6). Structure is task dependent.
- Width (where does adding workers plateau?): not isolated. Mode changes add review/specialist and change rounds together; no empirically supported universal width limit.
- Role → model placement (which tier where, cost vs quality): no cross-tier model placement experiment. GPT-5 mini assigns SQuAD drafter to domain skill 87.50%, GPT-OSS to reasoning 73.50%; Llama specialist selection is more diffuse (§5.3/Figure 4, p.8).
- Verification / review effects: SQuAD unanswerable abstention: baseline 0% for all; flat 0–3.02%; AUTO 19.39–36.56% (Table 3, p.9). Review, role assignment, answer formatting and gating are bundled; causal contribution of reviewer alone is unknown. CCO checks structure, not truth.
- Cost / tokens / latency: hierarchy uses 46.38–79.31% fewer tokens than flat (Table 1). GPT-OSS SQuAD 13,021→3,318; single-agent 425 tokens. Thus cheaper than flat still costs ~7.8× single-agent. Latency unmeasured. Table 2 differs from Table 1 for some MuSiQue token totals; use Table 1 for structure comparisons.
- Failure modes observed: fixed round caps can terminate unresolved debate and propagate hallucinations; structured organization loses on some narrative reasoning (§Limitations, p.9).

## Implications for Hannibal's Army (label each as INFERENCE)
- Depth-1 design: INFERENCE: bounded drafter/reviewer/specialist interactions and selective activation are worth testing against an all-peers meeting.
- Depth-2 design: INFERENCE: this paper motivates separating planning, execution and final checks, but does not validate adding sub-orchestrators or banning managers from implementation.
- Which agent/model type goes in which seat: INFERENCE: assign roles by demonstrated task skill; use deterministic schema checks for compliance where possible. No evidence here ranks GPT versus Claude versus Gemini seats.
